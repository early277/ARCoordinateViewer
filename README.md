# 境界簡易AR / ARCoordinateViewer

座標や図面をAR・平面図で確認し、現地での作図、樹木調査、色付き点群の記録を行うiOSアプリです。画面の主な表示言語は日本語です。

このリポジトリは **1.8.0（build 76）** のソースを含みます。

点群の取得・補正の計算と処理順序は [技術説明](TECHNICAL_NOTES.md) を参照してください。

## 主な機能

### 座標・図面の表示

- KML、KMZ、CSV、SIMA、DXF、GeoTIFF、国土地理院の基盤地図情報DEMを読み込み、点・線・画地・点名などをAR画面と平面図に表示します。
- ファイルごとのレイヤー管理、表示切替、CSVの列割当、日本の平面直角座標系1～19系の指定に対応します。
- 現地に合わせて表示の位置・向き・高さを調整できます。GeoTIFFは背景画像または標高DEMとして利用できます。

形式ごとに対応範囲があります。任意のDXF要素、GeoTIFFの圧縮方式、すべての座標参照系を扱うものではありません。座標系は数値だけで判断せず、取込画面で確認してください。

### AR作図

点を順に指定して点や折れ線を記録します。読み込んだ図形の頂点や線の途中も利用できます。作図レイヤーの管理、斜距離・水平距離・垂直距離の表示、DXF出力に対応します。作業内容はアプリ内へ自動保存します。

### 樹木調査

樹木の直径と任意の樹高を測定し、番号・色・樹種名とともに記録します。直径の測定後に、直径だけ記録するか、続けて樹高を測るかを選べます。未測定の樹高は0mと区別します。最近使った樹種名の選択、保存一覧、CSV出力、記録の削除・復元に対応します。

### 色付き点群（試作）

LiDAR対応端末で、深度とカメラ画像から色付き点群を取得します。

- 収録中は開始・停止、GCP記録、直前のGCP操作を戻す操作を使用します。取得済みの範囲は軽量な点表示で確認できます。
- 停止時にアプリ内へ保存し、「保存した点群」のサムネイル付き一覧から再び開けます。PLYへの出力は任意です。
- 停止後はAR表示またはカメラ映像のないモデル表示で閲覧できます。モデルは回転・移動・拡大縮小、ダブルタップによる回転中心の変更に対応します。
- 保存点は収録中の表示用間引きと分離しています。大きな保存モデルはページに分けて表示し、PLYには選んだ記録の全保存点を出力します。
- GCPがなくても、未補正のローカル座標でPLYを出力できます。保存先は標準のフォルダ選択画面で指定します。

1記録には点数・フレーム数・保存容量等の上限があります。端末の空き容量が十分でも、記録上限に達すれば収録を終了します。追記再開は、同じARセッションで追跡と座標系の連続性を確認できる場合に限ります。保存記録を開き直した後や追跡を失った後の再開には対応しません。

### GCPと既知座標への対応付け

GCP（基準点）は、深度を使う方法か、異なる2か所から同じ点を狙う方法で記録します。二視点方式では十分な移動と交会角が必要です。同一スキャン内の近接GCPは再観測として扱い、候補が複数なら保留します。別番号で記録したGCPを、後から同じ点として指定することもできます。

保存後に「同じ点・座標を関連付ける」から、GCPと既知座標を手動で対応付けます。既知座標は、読み込み済みのAR点、手入力、表の貼付け、CSV・TXT・TSV・SIMAの座標レコード・xlsxから追加できます。点名・X・Y・高さを表で確認・編集し、平面図から対応点を選択できます。座標セットは保存して再利用できます。xlsxは既知座標表の入力用です。xls・xlsm・Numbersファイルの直接読込には対応しません。

補正は倍率を1に固定し、重力方向を保った水平回転と平行移動を基本にします。全体の位置合わせと、既知GCPの各観測のずれをフレームへ配分する方式を選べます。水平のみの補正、残差・RMSの確認にも対応します。元の点群・観測と対応表・補正結果は分けて保持し、未補正データも出力できます。

入力表のX・Y・高さの意味、単位、系番号、高さの基準を確認してください。AR内部はY軸が上向きです。公共座標とARの軸は内部で変換するため、表示上の軸名だけで同一とは扱いません。測地系・標高基準の相違を自動で解消する機能ではありません。

### Drogger BLE連携（試験機能）

対応するDrogger BLE受信機のGNSS位置を使い、AR表示の水平位置を補正します。受信機側のRTK設定とGGA・RMC・GSTの出力が必要です。測地系・時刻・アンテナ取付位置を確認し、連続したFIXと精度・時刻の条件を満たしてから補正します。

Droggerによる高さ・方位の自動補正、受信機設定、Ntrip接続の設定は行いません。受信機との実機接続・測位精度は別途検証が必要です。

### 写真・動画

AR表示を含む写真や動画を記録できます。写真には撮影位置・向き・座標基準などの付属情報を保存する場合があります。写真だけを共有する場合も位置情報等が含まれることがあるため、共有前に確認してください。

## 動作条件と制限

- iOS／iPadOS 18以降。AR機能にはARKit対応端末、色付き点群の取得にはLiDAR対応端末が必要です。
- AR表示・計測は、明るさ、対象表面、移動距離、追跡状態、入力座標、位置合わせの影響を受けます。既知寸法や独立した検証点で確認してください。
- 測量機器としての精度、境界確定・登記・公共測量の成果は保証しません。残差が小さいことだけでは絶対精度を保証できません。
- 点群補正には観測数・配置等の条件があります。端末の動きとAR姿勢の急変を運動センサーで補助的に判定しますが、すべての自己位置更新を識別・修復するものではありません。
- 大容量データやすべてのファイル構成に対応するものではありません。収録・保存・出力のエラーや上限表示を確認してください。

## ビルド

開発には、iOS 18以降のSDKを利用できるXcodeが必要です。公開用ソースの確認環境はXcode 26.6です。

1. `AR境界簡易表示.xcodeproj` をXcodeで開きます。
2. Schemeに `AR境界簡易表示` を選択します。
3. 実機へ導入する場合は、Signing & Capabilitiesで自分のTeamと一意のBundle Identifierを設定します。公開プロジェクトには開発者のTeamを設定していません。
4. 対応端末を選んでビルド・実行します。カメラ・位置情報等の権限は、利用する機能に応じて端末上で許可してください。

署名なしでコンパイルを確認する例です。端末へのインストールは行いません。

```sh
xcodebuild \
  -project 'AR境界簡易表示.xcodeproj' \
  -scheme 'AR境界簡易表示' \
  -configuration Release \
  -destination 'generic/platform=iOS' \
  -derivedDataPath ./DerivedData \
  CODE_SIGNING_ALLOWED=NO build
```

外部パッケージの追加は不要です。主にSwiftUI、ARKit、SceneKit、MapKit、Core Location、Core Bluetooth、Core Motion、ReplayKit等のAppleフレームワークを使用します。

## 確認とデータの取り扱い

手動の確認項目は [XCODE_TEST_CHECKLIST.md](XCODE_TEST_CHECKLIST.md) を参照してください。`ARDrawingUITests` Schemeには一部の画面操作テストがあります。Simulatorや合成入力の結果は、実機のLiDAR・GNSS精度や負荷の検証を代替しません。

アプリの作業・点群・樹木記録は端末内へ保存します。点群の完全削除は元に戻せません。樹木の削除は復元用記録を保持します。外部へ出力したファイルは、それぞれの保存先で管理してください。

開発者サーバーへの自動アップロード、広告SDK、アクセス解析SDK、アカウント登録はありません。地図や端末の同期、ユーザーが選んだ共有先には各サービスの設定が適用されます。詳細は [プライバシーポリシー](PrivacyPolicy.md) を参照してください。

不具合報告はGitHub Issuesへお願いします。私有地の座標、写真、個人情報、機密図面を公開の投稿へ添付しないでください。再現例には合成データを使用してください。
